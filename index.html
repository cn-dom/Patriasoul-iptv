PatriaSoul IPTV

Desktop IPTV player za Windows s podrškom za uvoz M3U/M3U8 playlista, kategorije, pretraživanje, favorite i HLS reprodukciju.

Ovo je stranica projekta, a ne sam player.

PatriaSoul IPTV je Windows desktop aplikacija i ne pokreće se izravno u pregledniku. Za instalaciju preuzmi Windows paket iz GitHub Actions izrade.
